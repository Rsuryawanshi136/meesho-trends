            How this report works
            • Every day at 12 PM, the first page of two public Meesho listings per category is read, in Meesho's default order. Nothing behind a login is used.
            • Meesho doesn't publish sales. All-time ranks by each product's total reviews. Today ranks by reviews gained since the previous morning, which tracks daily sales.
            • Only some buyers leave reviews, so compare products with each other rather than reading the numbers as exact order counts.
            • The written analysis is refreshed from each day's data.
